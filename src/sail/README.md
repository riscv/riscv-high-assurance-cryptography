The SCC KATs execute the Sail listings extracted from section 4.9.6 of
[Zkl-ISA-unpriv.adoc](../../modules/ROOT/pages/Zkl-ISA-unpriv.adoc).
They run separately from the Python locker and management KATs in `src/kat/`.

Install Sail and Z3, then run:

```sh
python3 src/sail/scc-kat.py --sail /path/to/sail
```

The suite was checked with Sail 0.20.3. `scc-kat.json` contains ten fixed
encryption vectors generated by executing the new Sail listings. Its hex
strings are byte strings in memory order, converted to values as little-endian
integers. Both the Sail listings and the existing Python SCC core must reproduce
these answers; the suite also checks them against the independent RFC 8452
construction, with the SCC changes applied.

The harness supplies the omitted AES and field multiplication operations through
tables of primitive inputs and outputs from `src/kat/common.py`; an unexpected
primitive input fails the test. It supplies block concatenation directly.
The listings themselves are extracted and executed without translating them.
Checks cover both segments, empty and nonempty plaintext, multi-block associated
data, key derivation, POLYVAL, counter wrap, input preservation, ADSDropped
masking, and authentication failures with zeroed plaintext. These functional
checks do not measure execution time.
