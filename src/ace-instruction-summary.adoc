[[ACE-instructions-overview]]
==== Instructions Overview

ACE provides a set of unprivileged instructions for cryptographic operations, state management, configuration, and secure data movement.
The notation `K[Xd]` or `K{Xd}`, for a GPR `Xd`, refers to the CR whose index is contained in `Xd`,
and `Kn|K{Xn}` indicates that the CR operand can be encoded either as an immediate index (`Kn`) or via a GPR (`K{Xn}`).

.The ACE Instruction Set
[width="100%",cols="20%,28%,52%",options="header",subs="+macros"]
|===
| Instruction | Operands | Description
| `ace.exec`
| A. `Vd, Kn\|K{Xn}, Vs2` +
  B. `Kn\|K{Xn}, Vs2` +
  C. `Vd, Kn\|K{Xn}` +
  D. `Kn\|K{Xn}`
| Performs a cryptographic operation defined by the algorithm and state of the CR. Supports four Forms based on whether vector input and/or output are used.
| `ace.setst`
| A. `Kd\|K{Xd}, #immed7` +
  B. `Kd\|K{Xd}, #immed7, Xs` +
  C. `Kd\|K{Xd}, #immed7, Vs`
| Transitions the cryptographic algorithm state within the CC. Auxiliary input can be passed in a GPR or vector register.
| `ace.mgmt`
| A. `Kd\|K{Xd}, #immed7` +
  B. `Kd\|K{Xd}, #immed7, Xs` +
  C. `Kd\|K{Xd}, #immed7, Vs`
| Manages the lifecycle states of a CR (e.g. provisioning, export, import preparation).
| `ace.load` +
  (`ace.sysimport`)
| `Kd\|K{Xd}, %offset(Xs1)`
| Loads serialized context or provisioning input from memory into a CR. `ace.sysimport` provides support for system formats.
| `ace.store`
| `%offset(Xs1), Ks2\|K{Xs2}`
| Exports serialized context from a CR to memory.
| `ace.clone`
| `Kd\|K{Xd}, Ks\|K{Xs}`
| Clones the complete configured state of a source CR to a destination CR.
| `ace.derive`
| A. `Kd\|K{Xd}, Ks1\|K{Xs1}` +
  B. `Kd\|K{Xd}, Ks1\|K{Xs1}, Xs2` +
  C. `Kd\|K{Xd}, Ks1\|K{Xs1}, Vs2`
| Derives a new CC in a destination CR using key material from a source CR (e.g., KEM shared secret).
| `ace.size` +
  (`ace.avail`)
| A. `Xd, Ks\|K{Xs}` +
  B. `Xd, Xs` +
  C. `Xd, Vs`
| Returns the size of an SCC or PI in bytes for a given CR or metadata header. Returns 0 if unsupported. `ace.avail` is an alias for Form B.
| `ace.getmdl` +
  `ace.getmdh` +
  `ace.getmdv`
| `Xd, Ks\|K{Xs}` (l, h) +
  `Vd, Ks\|K{Xs}` (v)
| Reads bits [63:0] (`getmdl`), bits [127:64] (`getmdh`), or all 128 bits (`getmdv`) of the Metadata Header of a CR.
| `ace.restrictl` +
  `ace.restricth` +
  `ace.restrictv`
| `Kd\|K{Xd}, Xs1` (l, h) +
  `Kd\|K{Xd}, Vs1` (v)
| Narrows Usage Policies or hardens security attributes in the Metadata Header. Weakening policies is not permitted.
| `ace.input`
| `%offset(Xs), Xl`
| Loads `Xl` bytes from memory into the ACEIOBUF at `acestart` (for `Zlio`).
| `ace.output`
| `%offset(Xs), Xl`
| Stores `Xl` bytes from the ACEIOBUF at `acestart` to memory (for `Zlio`).
| `ace.mv`
| A. `Kd\|K{Xd}, Xs2` +
  B. `Kd\|K{Xd}, Vs2` +
  C. `Xd, Ks1\|K{Xs1}` +
  D. `Vd, Ks1\|K{Xs1}`
| Dedicated register move instructions transferring scalar/vector register data to/from a CR (for `Zlmv`).
| `ace.clear`
| `Kd\|K{Xd}`
| Pseudo-instruction (`ace.setst` to _Off_). Clears and unconfigures a CR.
| `ace.reset`
| _none_
| Pseudo-instruction (`ace.setst` to _Off_ with indirect CR $X0$). Resets all CRs and the ACEIOBUF.
| `ace.getst`
| `Xd, Ks\|K{Xs}`
| Pseudo-instruction (`ace.getmdl` + shift/mask). Extracts the _State_ field of a CR.
|===
