  remaining C and D rows. The first matching row determines the outcome. If
  no row matches, the outcome is EXEC.

. *R2 (Destinations and partial progress.)* In any outcome other than EXEC,
  the instruction writes no vector register, no GPR, no ACEIOBUF octet, and
  no memory location. Exception: when a block-iterated `ace.exec`
  (<<ACE-resumability>>) encounters an error condition after fully
  processing `j` {ge} 1 blocks, the outputs of those `j` blocks remain
  written, the failing block and all later blocks are not written in any
  part, and `acestart` holds the octet count of the `j` completed blocks.
  The row's CR-state effects apply unchanged.

. *R3 (Trap semantics.)* For TRAP-ILL and TRAP-ACE outcomes the trapped
  instruction does not retire and `xepc` holds its address. Unlike ordinary
  RISC-V exceptions, a TRAP-ACE outcome _does_ commit the CR-state effects
  listed in its row before the trap is taken; re-execution of the same
  instruction therefore observes the updated CR state. This deviation is
  deliberate and implementations must not suppress these effects.

. *R4 (Entry into an Error State.)* Whenever a row specifies a transition to
  an Error State: the Content of the CR is cleared and its CRF resources may
  be released; _ImpDataLen_ is set to 0; _ConfigStatus_ is set to
  `ace_cfgst_complete`; all other MDH fields are preserved. This is the only
  definition of Error-State entry; rule 7 of <<ACE-State-field>> refers here.

. *R5 (Explicit Error States.)* `ace.setst` whose `#immed7` names an Error
  State is EXEC: it performs the transition with the entry actions of R4 and
  raises no exception (<<ACE-instruction-setst>>).

. *R6 (Configuration-phase exemption list.)* Row D1 does not apply to the
  instructions whose defined function is to operate on a CR that is
  unconfigured or partially configured, namely: `ace.mgmt`; `ace.load`,
  `ace.store`, and `ace.mv` (each gated on the _ConfigStatus_ values named
  in its own description); `ace.size`; `ace.getmd*` and `ace.getst`;
  `ace.setst` with `#immed7` equal to `ace_state_unconfigured` or an Error
  State (hence `ace.clear` and `ace.reset`). All other instructions naming a
  CR are subject to D1. An R6-exempt instruction issued while _ConfigStatus_
  holds a value not admissible for it also resolves per row D1.
